================================================================
    SCUM-RCON - Drop-In Install for a SCUM dedicated server
================================================================

This bundle adds a Source RCON server to a SCUM dedicated server.
It includes UE4SS + the scum_rcon mod, pre-configured and ready
to drop in. You set a password, the listener comes up, and any
standard Source RCON client can talk to it.

No RCON client is bundled here - use whichever you already have
(mcrcon, rcon-cli, BattleMetrics, RconShell, WebRcon, a custom
bot, ...). They all speak the same protocol. If your download
also contained SCUM-RCON-Setup-*.exe, that installer can place
a ready-to-run console for you on top of the mod.

================================================================
 REQUIREMENTS
================================================================

* A SCUM dedicated or local server you control.
* A working brain.
* An RCON tool (client)


================================================================
 QUICK-START INSTALL (5 minutes)
================================================================

1) Extract the contents of THIS bundle (everything next to this
   INSTALL.txt -- "dwmapi.dll" and the "ue4ss" folder) into your
   dedicated server's Win64 folder:

   	<ServerInstall>\SCUM\Binaries\Win64\

   The result should look like:

       Win64/
        |-- dwmapi.dll                            <- from this bundle
        |-- SCUMServer.exe                        <- already there
        |-- ue4ss/                                <- from this bundle
        |   |-- UE4SS.dll
        |   |-- UE4SS-settings.ini
        |   |-- LICENSE
        |   \-- Mods/
        |       |-- mods.txt
        |       \-- scum_rcon/
        |           |-- dlls/main.dll
        |           |-- config.ini                <- EDIT THIS
        |           |-- enabled.txt
        |           |-- README.md
        |           \-- plugin-api/               <- for Lua/C++ plugin authors
        \-- ... (other server files)

2) Open ue4ss/Mods/scum_rcon/config.ini and set a real password:

   	password = use-a-real-password-here

   The listener REFUSES to start while the password is still
   "CHANGE_ME_BEFORE_USE". The default port is 28015 (change it
   in config.ini if you like).

   IMPORTANT: in this file a comment must sit on its OWN line.
   Anything after a value on the same line becomes part of that
   value - "password = secret ; my note" sets the password to
   "secret ; my note".

3) Start the server.

4) Verify the mod loaded.
   Open: <Win64>\ue4ss\UE4SS.log
   Look for the banner:

   [SCUM-RCON] init - v0.5.1
   [SCUM-RCON] SCUM-RCON ready - listening on 0.0.0.0:28015

   If you see "RCON listener NOT started: password is unset or
   still the default", go back to step 2.

5) Connect with any Source RCON client. For example, with mcrcon
   (not bundled -- download separately if you want it):

   	mcrcon -H <server-ip> -P 28015 -p <your-password> -t

   At the prompt, type: ListSquads

   Any client that speaks Source RCON works the same way.

   Every command also works straight from the in-game admin chat
   with a '#' in front of it, e.g.:  #ListSquads

================================================================
 USING THE COMMANDS
================================================================

See USAGE.md (next to this file) for the full command guide:
how to send commands, which commands need a player's SteamID,
the notification and chat-colour codes, the spawn-location forms,
and the common mistakes.

Running the server under Linux (WINE / Proton)? See
INSTALL_LINUX.md next to this file - one extra environment
variable is needed before the mod loads at all.

Writing your own commands? plugin-api/PLUGIN_API.md documents how
a UE4SS Lua mod (or a C++ mod) registers commands with SCUM-RCON.

================================================================
 IMPORTANT WARNINGS
================================================================

* USE AT YOUR OWN RISK. No warranty. No guarantee against future
  game updates breaking the mod, and no guarantee against bans.

* DO NOT expose the RCON port to the open internet without a
  strong password. The protocol does not encrypt traffic.

* Five wrong passwords from the same address lock that address
  out for five minutes. That includes you, so type carefully.
